# 🔐 AI-Based Social Engineering Attack Simulation & Forensic Analysis

## 📌 Overview
This project demonstrates a simulated social engineering attack enhanced with AI-generated deepfake content. The objective is to understand modern phishing techniques and analyse them using digital forensic methods.

---

## 🎯 Objectives
- Simulate a phishing attack using social engineering techniques
- Analyse attack behavior using digital forensics
- Identify indicators of compromise (IoCs)
- Understand the impact of AI-generated deepfake attacks

---

## 🛠 Tools & Technologies
- Ubuntu (Virtual Machine)
- VirtualBox
- Zphisher (Phishing simulation tool)
- URLScan / DNS Analysis Tools
- AI Video Generator (Deepfake simulation)

## ⚙️ Methodology

### 1. Lab Setup
- Created a virtual environment using VirtualBox
- Installed Ubuntu OS for safe testing

### 2. Attack Simulation
- Generated phishing link using Zphisher
- Applied URL masking techniques
- Delivered attack via social media simulation
- Created a fake login page for credential capture

### 3. Data Capture
- Simulated credential submission in controlled environment
- Observed how users interact with phishing interfaces

### 4. Forensic Analysis
- URL analysis using online tools
- IP address and DNS investigation
- Source code inspection of cloned website
- Detection of phishing indicators

---

## 🔍 Key Findings
- AI-generated content increases trust and attack success rate
- Social media platforms are effective phishing vectors
- URL masking hides malicious intent effectively
- Human behavior is the weakest security layer

---

## 📊 Results
The simulation successfully demonstrated:
- Credential harvesting in a controlled environment
- Effectiveness of social engineering techniques
- Importance of forensic investigation in detecting attacks
